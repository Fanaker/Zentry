# Changelog

## 2.2.0 — Stable web and Android source

- Refined the transaction form layout, calendar control contrast, brand icon and responsive UI.
- Simplified the dashboard by removing an unnecessary balances / receivables summary block.
- Improved the category configuration workflow and navigation.
- Retained transaction, budget, monthly closing, credit-card cycle, debts and Excel features.
- Continued the Android review-before-confirmation capture workflow using Gboard dictation and reusable phrase aliases.
- Consolidated source, SQL scripts, tests and native Android wrapper for independent hosting.

## Previous 2.x work

- Added mobile Gboard dictation and manual confirmation of draft movements.
- Improved capture parsing, alias handling and navigation on small screens.
- Moved the application away from Lovable-managed deployment toward an independently configured Supabase instance and a static web build.
